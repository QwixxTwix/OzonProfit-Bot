# Ozon Profit Bot

Автоматический помощник для выполнения заданий на платформе Ozon Profit.  
Позволяет автоматизировать рутинные задачи модерации товаров, разметки данных и сбора информации.

## ⚠️ Важно

- Использование бота **может нарушать правила платформы** – применяйте на свой страх и риск.
- Проект создан в образовательных целях, автор не несёт ответственности за последствия.

## 🚀 Возможности

- Автоматический переход по категориям заданий
- Интеллектуальный выбор ответа на основе встроенных правил
- Опциональное использование внешнего анализатора для сложных случаев
- Эмуляция поведения человека (движение мыши, задержки)
- Антидетект (undetected-chromedriver)
- Тёмная / светлая тема интерфейса
- Управление паузой и остановкой
