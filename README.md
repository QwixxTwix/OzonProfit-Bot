# Ozon Profit Bot 🤖

<img width="1255" height="724" alt="image_2026-08-30_03-26-24" src="https://github.com/user-attachments/assets/6a8c2f05-e513-4661-b113-ec30a60d3468" />

Автоматизированный помощник для выполнения заданий на платформе **Ozon Profit**.  
Бот самостоятельно находит доступные задачи, анализирует их содержание и выбирает правильные ответы, используя встроенные эвристики или внешний ИИ‑анализатор (OpenAI). Интерфейс выполнен на PyQt5 с поддержкой тёмной и светлой темы.

> **⚠️ Важно**  
> Использование бота может нарушать пользовательское соглашение Ozon. Проект создан в образовательных целях, автор не несёт ответственности за любые последствия от его применения. Используйте на свой страх и риск.

## 🚀 Основные возможности

- **Автоматический вход** в раздел заданий Ozon Profit.
- **Переключение между категориями** задач:  
  «Модерация товаров», «Разметка данных», «Сбор информации», «Полевые задания», «Смешанная разметка».
- **Интеллектуальное решение задач**:
  - Быстрые ответы на основе встроенных правил (запрещённые товары, неверные категории, 18+, противоречия в карточке и др.).
  - Опциональное подключение к OpenAI API (`gpt-4o` / `gpt-4o-mini`) для сложных случаев.
  - Анализ текста задания и изображений (если присутствуют).
- **Эмуляция поведения человека**:
  - Случайные задержки между действиями (настраиваются).
  - Имитация движения мыши (с использованием `pyautogui`).
  - Переключение на последнюю открытую вкладку.
- **Антидетект**:
  - Использование `undetected-chromedriver` для обхода систем обнаружения ботов.
  - Отключение флагов автоматизации в Chrome.
  - Сохранение профиля браузера для сохранения сессии.
- **Удобный графический интерфейс**:
  - Современный дизайн с тёмной и светлой темой.
  - Возможность изменения размера окна.
  - Панель управления с кнопками **Запуск**, **Пауза**, **Остановка**.
  - Лог‑поле с выводом всех действий и ошибок.
  - Вкладка настроек с редактированием параметров.
- **Гибкая настройка**:
  - URL главной страницы.
  - API‑ключ и модель анализатора.
  - Максимальное количество запросов к анализатору (ограничение бюджета).
  - Минимальная и максимальная задержка между действиями.
  - Включение/отключение эмуляции движений мыши.
- **Обработка ошибок**:
  - Перезапуск браузера при закрытии окна.
  - Обновление страницы при ошибках 403.
  - Ожидание при проблемах с VPN или соединением.
  - Автоматический переход к следующей задаче при невозможности решить текущую.

## 🔧 Установка и запуск

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/yourusername/ozon-profit-bot.git
   cd ozon-profit-bot
   ```

2. **Создайте виртуальное окружение** (рекомендуется)
   ```bash
   python -m venv venv
   source venv/bin/activate   # Linux/Mac
   venv\Scripts\activate      # Windows
   ```

3. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```
   > Если файла `requirements.txt` нет, установите вручную:
   > ```
   > pip install PyQt5 selenium requests pillow undetected-chromedriver pyautogui
   > ```

4. **Запустите бота**
   ```bash
   python OzonAsis.py
   ```

5. **Первая настройка**  
   - При первом запуске создаётся файл `ozon_config.json` со стандартными параметрами.  
   - В интерфейсе перейдите на вкладку **Настройки**, введите ваш API‑ключ OpenAI (если планируете использовать анализатор) и другие параметры, затем нажмите **Сохранить**.  
   - Нажмите **Запустить** – бот откроет браузер и начнёт работу.

## ⚙️ Конфигурация

Все настройки хранятся в файле `ozon_config.json` (создаётся автоматически).  
Основные параметры:

| Параметр | Описание |
|----------|----------|
| `theme` | `"dark"` или `"light"` |
| `url` | URL главной страницы заданий (по умолчанию `https://profit.ozon.ru/cabinet/tasks`) |
| `analyzer_api_key` | API‑ключ OpenAI (необязательно) |
| `analyzer_model` | Модель анализатора (`gpt-4o` или `gpt-4o-mini`) |
| `max_requests` | Максимальное количество запросов к анализатору за сессию |
| `delays.min_between_actions` | Минимальная задержка между действиями (сек) |
| `delays.max_between_actions` | Максимальная задержка между действиями (сек) |
| `antibot.random_mouse_movement` | Включить эмуляцию движений мыши |

Настройки можно изменять как через интерфейс, так и вручную в JSON‑файле.

## 🧠 Как работает принятие решений

1. **Анализ задания**  
   - Извлекается текст страницы и (опционально) изображение.  
   - Определяется тип задачи (модерация, поиск, валидация, разметка, полевое).

2. **Встроенные правила** (без вызова API)  
   - Проверка на наличие запрещённых товаров (наркотики, оружие, алкоголь, табак, порнография и др.).  
   - Определение неверной группы товаров (например, бонг в категории «Аптека»).  
   - Противоречия в карточке (фото не соответствует названию).  
   - Ошибки в указании бренда.  
   - Отсутствие маркировки 18+.  
   - Если правило сработало – бот выбирает соответствующий вариант и переходит к следующему заданию.

3. **Использование анализатора** (если ключ API задан)  
   - Формируется промпт с текстом задания, вариантами ответов и строгими инструкциями.  
   - Отправляется запрос к OpenAI.  
   - Ответ парсится – извлекается номер варианта.  
   - Если ответ не содержит цифры, выполняется поиск совпадений по тексту.  
   - В случае ошибки или неопределённости – применяется фолбэк (выбор «Все атрибуты заполнены верно» или пропуск).

4. **Обработка полевых заданий** – пропускаются (требуют физического присутствия).

5. **Если ни один вариант не выбран** – бот просто нажимает «Далее» и переходит к следующей задаче.

## 🛠️ Технические детали

- **GUI**: PyQt5 (без рамок, с кастомными элементами и частицами на фоне).  
- **Браузерный движок**: Selenium + `undetected-chromedriver` (опционально).  
- **Сохранение сессии**: профиль Chrome хранится в папке пользователя `~/OzonBotProfile`.  
- **Мультипоточность**: бот работает в отдельном потоке (QThread), чтобы не блокировать интерфейс.  
- **Логирование**: цветные эмодзи для наглядности.  
- **Обработка изображений**: библиотека Pillow для конвертации в JPEG.
